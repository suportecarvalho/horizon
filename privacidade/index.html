POLÍTICA DE PRIVACIDADE (LGPD) – TERRA HOSTIL Última atualização: 16 de agosto de 2026 1. Quem somos Esta Política descreve como o Rust Horizon trata os dados pessoais dos jogadores, em conformidade com a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018). 2. Dados que coletamos 2.1 Dados de identificação - SteamID - Nome de exibição da Steam (quando disponível) - Discord ID (quando você vincula a conta) 2.2 Dados de compra - Informações do pedido (produto, valor, data) - Status do pagamento (processado pelo Mercado Pago) 2.3 Dados técnicos - Endereço IP - Data e hora de acesso - Informações básicas do navegador (quando necessário para segurança) Não coletamos CPF, endereço residencial ou dados bancários diretamente. O pagamento é processado pelo Mercado Pago. 3. Para que usamos os dados - Identificar você no servidor e entregar os benefícios comprados - Processar e confirmar pagamentos - Prevenir fraudes e abusos - Cumprir obrigações legais - Melhorar a experiência no site e nos servidores 4. Base legal (LGPD) Tratamos os dados com base em: - Execução de contrato (entrega do que você comprou) - Legítimo interesse (segurança e prevenção de abuso) - Cumprimento de obrigação legal (quando aplicável) 5. Com quem compartilhamos - Mercado Pago (processamento de pagamento) - Steam (autenticação) - Discord (quando você vincula a conta) - Prestadores de infraestrutura técnica (hospedagem) Não vendemos seus dados. 6. Tempo de retenção Mantemos os dados pelo tempo necessário para: - Cumprir as finalidades acima - Atender obrigações legais - Resolver disputas Pedidos e registros de entrega podem ser mantidos por prazo maior para auditoria e segurança. 7. Seus direitos (LGPD) Você pode solicitar: - Confirmação da existência de tratamento - Acesso aos dados - Correção de dados incompletos ou desatualizados - Anonimização, bloqueio ou eliminação de dados desnecessários - Informação sobre compartilhamentos - Revogação do consentimento (quando aplicável) Para exercer seus direitos, entre em contato pelo Discord do Rust Horizon. 8. Segurança Adotamos medidas técnicas e organizacionais para proteger os dados contra acessos não autorizados, perda ou alteração indevida. 9. Cookies O site pode utilizar cookies essenciais para funcionamento (sessão de login e segurança). Não utilizamos cookies de publicidade de terceiros. 10. Alterações Esta Política pode ser atualizada. A versão mais recente estará sempre disponível nesta página. 11. Contato Dúvidas sobre privacidade: Discord do Rust Horizon.
